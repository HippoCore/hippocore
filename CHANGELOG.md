# Changelog

All notable changes to Hippo Core are documented here.

## 1.3.0

- Added automatic ambient recall and selective remember policies for Codex, Claude Code, and Cursor.
- Added one-command shared-vault installation with safe backups and idempotent repair.
- Added local offline embeddings and model-optional memory extraction.
- Added concurrency-safe SQLite WAL storage for independent MCP clients.
- Added governed evidence history, conflict resolution, retraction, and atomic multi-fact memory.
- Added transparent token-savings estimates and recent recall comparisons to the dashboard.
- Added background dashboard lifecycle, safe uninstall, cross-platform CI, and provenance-enabled releases.
