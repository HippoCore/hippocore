# Security Policy

## Supported versions

Security updates are provided for the latest published version of Hippo Core.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Use GitHub's private vulnerability reporting feature in the Security tab of the HippoCore/hippocore repository.

Include the affected version, operating system, reproduction steps, impact, and any suggested mitigation. We will acknowledge a complete report within five business days and coordinate disclosure after a fix is available.

Never include API keys, access tokens, private memory databases, or personal memory contents in a report.
